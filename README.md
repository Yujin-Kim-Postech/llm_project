# insurance-rq-tree (starter)

A structured and extensible research classification system for insurance-related academic papers.

This repository provides:
- A hierarchical ontology (L1/L2)
- Semi-automated labeling workflow
- A review queue for manual validation
- A tree builder for visualization (D3-compatible JSON)

The system is designed to be **extensible and governance-ready**, recognizing that no ontology can perfectly anticipate future research fields.

---

## 📦 What is included

- `data/papers.jsonl`  
  Sample paper objects (one JSON per line)

- `labels/paper_labels.jsonl`  
  Confirmed L1/L2/tags for labeled papers

- `labels/review_queue.jsonl`  
  Autogenerated L1 suggestions (you manually fill `final_l1` / `final_l2`)

- `ontology.yaml`  
  Official L1/L2 classification standard

- `src/`  
  Scripts for suggestion generation and tree construction
