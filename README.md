# Insurance-RQ Generator

A structured and extensible research classification system for insurance-related academic papers.

This repository provides:
- A structured Topic_L1/opic_L2 research classification system
- A tree-building pipeline
- A Streamlit-based visualization app
- A governance-ready, extensible categorization framework
- A LLM-based research question generator

The system is designed to evolve with the literature.  
No ontology is permanently fixed.

---

## 📦 File Structure

- `data/RQ_generator_dataset.xlsx`  
  **Raw data source.**  
  Contains the original paper metadata.  
  Each paper must include Topic_L1 and Topic_L2 category fields.

- `data/category_schema.json`  
  Schema defining the top-level categories for Y (dependent variable) classification.

- `src/build_tree.py`  
  Script that reads `data/RQ_generator_dataset.xlsx` and constructs hierarchical tree data.

- `src/update_y_category.py`  
  Script that uses OpenAI to classify and update Y categories for papers based on their summaries.

- `tree.json`  
  Tree-structured data generated by `src/build_tree.py`.  
  Used for visualization.

- `app.py`  
  Streamlit application for interactive visualization of the research tree.

- `requirements.txt`  
  List of Python dependencies required for the project.

## 🚀 Basic Workflow

### 0️⃣ Installation

Install the required dependencies:

``` bash
pip install -r requirements.txt
```

Make sure you have a `.env` file in the project root with your OpenAI API key:

```
OPENAI_API_KEY=your_api_key_here
```

This project follows a simple five-step workflow.

------------------------------------------------------------------------

### 1️⃣ Update Raw Data

Edit or append paper entries in:

    data/RQ_generator_dataset.xlsx

Each paper must include at least the following columns in the Excel file:

- journal: Publication journal name (AB, EAJ, Extremes, IME, JRI, JRU, JRF, NAAJ, RMIR, SAJ)
- title: Paper title
- year: Publication year (2010-2025)
- doi: Digital Object Identifier
- first_author: First author's name
- study_type: "theory" or "empirical"
- theoretical_summary: Summary if study_type is "theory"
- Dependent_Variable_Y: Dependent variable description
- Proxy_for_Y: Proxy for dependent variable
- Independent_Variable_X: Independent variable description
- Proxy_for_X: Proxy for independent variable
- methodology: Research methodology
- dataset_and_period: Dataset and time period
- control_variables: Control variables used
- unit_of_analysis: Unit of analysis
- results: Key results
- keywords: Paper keywords
- Topic_L1: Level 1 category
- Topic_L2: Level 2 category

If a paper does not fit any existing category:

``` xlsx
{
  "Topic_L1": "Others",
  "Topic_L2": "Others"
}
```

(See governance rules below for how to create new categories.)

------------------------------------------------------------------------

### 2️⃣ Update Y Categories

Classify the dependent variables (Y) for new or updated papers:

``` bash
python src/update_y_category.py
```

This script uses OpenAI to analyze paper summaries and assign appropriate Y categories based on the schema in `data/category_schema.json`.

------------------------------------------------------------------------

### 3️⃣ Push Changes

After editing `data/RQ_generator_dataset.xlsx` and running the update script, commit and push:

``` bash
git add data/RQ_generator_dataset.xlsx
git add tree.json
git commit -m "Update papers data and rebuild tree"
git push
```

------------------------------------------------------------------------

### 4️⃣ Build Tree Data

Generate the hierarchical tree structure:

``` bash
python src/build_tree.py
```

This creates:

    tree.json

`tree.json` is the structured dataset used for visualization.

------------------------------------------------------------------------

### 5️⃣ Run Streamlit App

Launch the interactive research tree:

``` bash
streamlit run app.py
```

The application will open automatically in your browser.

------------------------------------------------------------------------

## 🔁 Category Governance Rule (Important)

If a paper does **not clearly fit** into any existing L1/L2 category:

    Topic_L1: Others
    Topic_L2: Others

If multiple papers accumulate in `Others`, you must:

1.  Propose a new L2 (or L1 if necessary)
2.  Update the category list in `README.md`
3.  Reclassify affected papers in `data/RQ_generator_dataset.xlsx`
4.  Rebuild the tree

This system is intentionally **extensible**.\
The category structure is not fixed and must evolve with new research
themes.
